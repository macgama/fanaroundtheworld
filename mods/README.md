# Mods (Steam Workshop)

Le jeu utilise des noms de clubs fictifs et aucun logo officiel.
Ce dossier accueillera le format des mods qui permettront à la communauté
de renommer les clubs, changer les couleurs ou ajouter des écussons via le Steam Workshop.

Le format exact sera défini plus tard (probablement des fichiers JSON + images dans `data/`).
