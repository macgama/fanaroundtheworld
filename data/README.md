# Données du jeu

Données au format JSON, lues par le jeu au démarrage.

- `clubs/` : clubs fictifs (nom, ville, couleurs, ligue). Aucun nom ni logo officiel.
- `calendriers/` : calendriers et résultats des vrais matchs, par saison et par ligue.
- `saisons/` : contenu de chaque saison du PASS (paliers, récompenses).
